# FFT & Signal Processing

> **View online:** https://deepbox.dev/examples/42-fft-signal-processing

FFT and signal processing tools new in v1.0.0: fft, ifft, rfft, irfft, fft2, ifft2, fftn, and spectral analysis utilities.

## Deepbox Modules Used

| Module            | Features Used                                     |
| ----------------- | ------------------------------------------------- |
| `deepbox/ndarray` | fft, ifft, rfft, irfft, fft2, tensor, linspace    |

## Usage

```bash
npm run example:42
```
