# Advanced Neural Networks

> **View online:** https://deepbox.dev/examples/39-advanced-neural-networks

Advanced NN features new in v1.0.0: Trainer with EarlyStopping, weight initialization, Embedding layers, normalization layers, containers, and advanced activations.

## Deepbox Modules Used

| Module          | Features Used                                                                     |
| --------------- | --------------------------------------------------------------------------------- |
| `deepbox/nn`    | Trainer, EarlyStopping, ModelCheckpoint, Embedding, GroupNorm, LayerNorm, PReLU, GELU, ModuleList, Sequential, Linear, ReLU, Dropout, xavierUniform, kaimingNormal |
| `deepbox/optim` | Adam                                                                              |
| `deepbox/ndarray` | tensor, parameter, GradTensor                                                  |

## Usage

```bash
npm run example:39
```
