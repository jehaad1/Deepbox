## A note on lazy-view operations

Rows marked † are lazy-view or spec-build operations whose Deepbox median is below the 1 µs timer floor. Deepbox implements `transpose`, `reshape`, `head`, `tail`, `iloc`, slicing and figure assembly as deferred metadata rewrites that do not depend on input size: a lazy strided view or an in-memory spec. No data moves until a consumer such as `.copy()`, `show()` or iteration needs it. The Python side of these cases usually materializes a fresh array, DataFrame or figure. The reported speedup therefore measures deferral, not throughput. It stays roughly constant however large the input is, which marks it as a timer-floor comparison and not a compute win.

To keep the comparison fair:

- `transpose`, `flatten` and `slice` in the NDArray suite wrap the Deepbox result in `copy(...)`, so both sides materialize a contiguous buffer (matching NumPy's `.T.copy()`, `.flatten()` and `[...].copy()`). These are realized-work comparisons.
- Plot spec-build cases (`scatter`, `bar`, `pie` and similar) that only append to a figure spec are recorded as local (non-comparable) and excluded from both rates. The `show (SVG)`, `show (PNG)` and `saveFig (PDF)` cases render on both sides and remain the comparable plotting benchmarks.
- The realized-work rate also drops any remaining sub-µs lazy view, so the headline number covers operations that move data.

## Notes

- Speedup above 1x means Deepbox is faster.
- Speedup below 1x means the Python package is faster.
- Two win rates are reported: overall (all comparable cases) and realized-work (excludes sub-µs lazy-view and spec-build cases marked †).
- Winners are chosen by `median_ms`. Local-only cases are excluded from both totals.
- The harness is symmetric: identical warmup, adaptive batching, sample counts and median selection on both sides.
- NumPy and SciPy use C and Fortran BLAS backends. Deepbox is pure TypeScript on V8.
- PyTorch uses the C++ ATen backend. All measurements are CPU-only.
- scikit-learn uses Cython and C extensions for core algorithms.
- Results depend on the hardware. Compare only on the same machine.
